Secure Data Exchange Protocol

Overview

This project was developed as a university graduation project to explore secure data exchange between client and server applications.

The application demonstrates the use of cryptographic algorithms, data integrity verification, and digital signature concepts within a Java-based application.

Features

Client-server communication using TCP/IP.

Implementation and demonstration of cryptographic algorithms.

Data integrity verification.

Digital signature concepts.

Graphical user interface for interacting with the application.

Technologies Used

Programming Language: Java

GUI Framework:Java Swing 

Networking: TCP/IP

Cryptographic Concepts: RSA, ElGamal, Serpent, and MD5 hashing.

Project Structure

The source code is organized into Java classes responsible for cryptographic operations, networking, and application functionality.

Learning Objectives

Understanding client-server communication.

Exploring cryptographic algorithms and their roles.

Applying data integrity and digital signature concepts.

Building a graphical interface for a Java application.

Disclaimer

This project was developed for educational purposes as a university graduation project. It has not been independently audited for security and should not be used to protect sensitive production data without further review.
